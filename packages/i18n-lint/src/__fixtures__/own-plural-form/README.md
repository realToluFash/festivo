# own-plural-form

Plural forms a locale has and English does not. Spanish's `guests_many` is
allowed; French's `guests_few` is not a French form, Portuguese's
`greeting_many` belongs to no family in English, and French's `guests_many`
renames the slot it shares with `guests_other`.

Used by parity.test.ts to prove the check allows the one and fails the rest.
